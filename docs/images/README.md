# 展示图规格

README 里引用的图片都在这个目录。**替换时只要用同名文件覆盖即可，README 不需要改。**

当前放的是占位图，尺寸已经对齐，替换后不会出现排版跳动。

## 统一要求

| 项目 | 要求 |
| --- | --- |
| 格式 | 静态图 `PNG`，动图 `GIF` |
| 像素密度 | 按 2 倍图导出（下面表格里的尺寸就是最终显示尺寸的 2 倍） |
| 体积 | PNG 单张 < 500 KB，GIF < 8 MB |
| 字体 | 中文用苹方或思源黑体，英文数字用 Inter |
| 配色 | 主色 `#0A7AFF`，辅助 `#22D3EE`，深色底 `#0B1220` |
| 截图 | 请清空真实客户名、真实项目名、内部链接 |

## 需要的图

| 文件名 | 尺寸 | 用在哪 | 画什么 |
| --- | --- | --- | --- |
| `banner.png` | 1600 × 480 | 页面最顶部 | 左侧放「AxureForge CLI」大标题和 slogan「批量改原型，不用一个个点」；右侧留白或抽象图形 |
| `demo.gif` | 1200 × 675 | 「演示」 | 一段终端录屏：新建项目 → 查页面 → 加一个元件，20 秒内，字号调大保证手机上也看得清 |
| `social-preview.png` | 1280 × 640 | 不在 README 里 | GitHub 仓库的社交预览图，做好后到仓库 Settings → Social preview 上传 |

## 怎么替换

1. 按上表尺寸做好图，文件名保持一致；
2. 覆盖本目录下的同名文件；
3. 提交后 GitHub 上自动更新，README 一个字都不用动。

如果某张图暂时不想要，把 README 里对应的 `<img>` 那行删掉即可，不会影响其他内容。
