# AxureForge v0.3.0

新增工作目录证据链、可复用 HTML 布局计划、索引新鲜度检查及 batch 结果引用。命令和参数声明可通过 `capabilities --json` 一次获取。目录包默认替代单文件分发，目标机器仍无需 Python。

## 行为

- HTML 一次导入生成 RP、plan、index、report、summary；`--work-dir` 指定数据目录，默认 `.forge/`。
- 固定宽度、高度自动延展；`--page-mode fixed` 固定画布。`--viewport` 保留。
- `html plan` 与 `html import --plan` 支持输入及实际资源哈希校验，复用不运行布局。
- 修复 flex shrink 权重、margin/gap、min/max 冻结分配及绝对定位 flex 自适应宽度。
- 文本测量/内在尺寸缓存，测量完成后平移放置；可加载带来源、版本的字体因子。
- `dump`、`verify`、`--index` 和批量 `as` / `$ref` 缩短查询与创建后确认流程。
- 结构检查与布局估算明确区分，视觉和交互未自动验证；未知重叠/边框意图不猜测。

## 本机验证

macOS ARM64，同机启动对比（旧单文件版本的前三次测量，与新目录包五次测量的中位数）：

| 命令 | 优化前 | 优化后 | 降幅 |
| --- | --- | --- | --- |
| `--version` | 2.942s | 0.060s | 98.0% |
| `--help` | 2.801s | 0.085s | 97.0% |

长页面看板 dry-run：84 个节点，主流程 2 次 CLI 调用，额外 page/node 查询 0 次，GUI 打开 0 次。索引约 104.2 KiB。创建后直接引用 ID、计划复用、旧输入拒绝与固定画布门禁均验证。

性能数据是本机样本，不代表所有项目或操作系统。用户提供历史会话中的 58 次结构查询不是同一 fixture，未作为严格同任务时间对比。默认不包含 GUI 或交互实测。

发布同时附带隔离二进制验证、工作流 dry-run、代码包安装验证及测试结果。Windows/Linux 由原生 CI 构建和验证，结果以对应报告为准。

## 安装迁移

解压后保留整个目录，包含 `_internal`。不要只复制主程序。macOS skill 安装器校验整个目录后切换入口，失败保留原安装。
旧 CLI 命令与 protocol-v2 保留；新能力要求 CLI 0.3.x。skill 的普通任务不再反复查询版本、展开全页或打开 Axure。
